# What, when, where, why, how

what - this folder is for any additions, edits, or removals from the wiki in relation to the config. If anything is not reflected correctly in the wiki, those fixin's go here as markdown for the next agent that will make the corrections. 

when - whenever a fix is found, created, or brought by the user, lowcache. This folder is proactive, reactive, retroactive, and active? sure. It's my quick and dirty solution to wiki drift. 

where - here and then the wiki directory is at ~/CodeRepo/sites/blogs/wiki

why - Too many errors were being found where the wiki did not reflect the config, or a bunch of granular changes were stacking up and  not getting the attention because of their size. This is here to ensure that edits are made, if not in a timely manner, correctly at the eventual time of wiki edits. 

how - any time a configuration change/edit/fix is made to the volnix config that would alter/affect the wiki in as far as how the config is reflected, add the fix into a markdown file here, which will be added to a todo list, which will be given to an agent for the update process. 

Open to suggestions for a better system, thats more automated. But thats a bigger problem than a folder and some instructions.
